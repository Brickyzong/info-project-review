### 过程中踩的 3 个坑（都已解决并固化进脚本）

**坑 1：`mvn spring-boot:run` 报 "找不到或无法加载主类 com.xmps.XmpsApplication"**
- 先以为是编译问题 → `clean compile` 后 35 个源文件重新编译成功，但错误依旧。
- 真实原因：**项目路径含中文与特殊字符**（`.../2026.7-9数智化轮岗/...`），
  spring-boot:run 在 fork JVM 拼接 classpath 时解析失败。
- **解决：改为 `package -DskipTests` 打可执行 jar，再 `java -jar` 启动**，完全绕开。
  这也是生产环境标准运行方式。
- 注意：`mvn test` 不受影响（surefire 有自己的 classpath 处理），所以测试一直能跑通。

**坑 2：Tomcat 起了随机端口 52415，不是配置的 8080**
- application.yml 明确写着 `server.port: 8080`，jar 内配置也是 8080，环境变量 SERVER_PORT 未设置，
  grep 全项目也找不到任何 `port: 0`。原因**未查明**。
- **解决：启动时显式传 `--server.port=8080` 覆盖**，已写进 run.sh 默认参数。

**坑 3：`Error: Unable to access jarfile /g/yd-work/...`**
- 把 Git Bash 格式路径（`/g/...`）传给了 java.exe，Windows 程序需要 `G:/...`。
- 这是老坑（记忆里已记过 JAVA_HOME/PATH 格式混用），这次又栽在 jar 路径上。
- **解决：run.sh 中区分 `JAR_WIN`（Windows 格式给 java）与 `JAR_BASH`（bash 格式做 `-f` 判断）。**

### curl 速查（服务在 8080 时，项目根目录下执行）
```bash
# 健康检查（不花钱）
curl -s http://localhost:8080/actuator/health

# 查已有任务（不花钱，立即返回完整报告）
curl -s -H "Authorization: Bearer test-key-001" \
  http://localhost:8080/api/v1/review/tasks/rev_20260904_001

# 一条龙：提交 → 提取 taskId → 查审查中 → 等 20s → 查已完成
TASK=$(curl -s -X POST http://localhost:8080/api/v1/review/tasks \
  -H "Authorization: Bearer test-key-001" \
  -F "file=@src/test/resources/sample/泰兴市智慧市场监管平台二期建设方案.docx" \
  -F "project_name=泰兴市智慧市场监管平台二期建设项目" \
  -F "project_type=建设" | grep -o 'rev_[0-9]*_[0-9]*')
echo "taskId = $TASK"
curl -s -H "Authorization: Bearer test-key-001" http://localhost:8080/api/v1/review/tasks/$TASK | head -c 400
sleep 20
curl -s -H "Authorization: Bearer test-key-001" http://localhost:8080/api/v1/review/tasks/$TASK | head -c 600
```
- 每次提交真实调用 DeepSeek，约 10 秒出报告。
- Git Bash 换行用 `\`；PowerShell 要换成反引号 `` ` ``。
- 返回 `code:401` = API key 不对（dev 默认 test-key-001 / test-key-002）。
