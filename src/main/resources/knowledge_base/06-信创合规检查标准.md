# 信创合规检查标准

## 审查目的
确保信息化项目软硬件选型符合国产化（信创）要求，逐项核验四类核心软硬件的国产化情况。

## 四类核心软硬件

| 序号 | 类别 | 检查要点 | 常见国产化方案 |
|------|------|----------|---------------|
| 1 | 芯片 | 服务器/终端是否采用国产芯片 | 鲲鹏、飞腾、龙芯、申威、兆芯、海光 |
| 2 | 操作系统 | 是否采用国产操作系统 | 麒麟、统信UOS、中科方德 |
| 3 | 数据库 | 是否采用国产数据库 | 达梦、人大金仓、南大通用、神通、瀚高、OceanBase、TiDB、openGauss |
| 4 | 中间件 | 是否采用国产中间件 | 东方通、中创、金蝶、普元 |

## 输出格式

对每项软硬件，标注：
- **通过**：明确采用国产产品
- **不通过**：未采用国产产品，需说明理由
- **未涉及**：方案中未涉及该类别
- **存疑**：方案中提及但未明确产品选型，需补充说明

## 审查方法

1. 从方案文档中提取技术选型信息
2. 与信创产品库进行匹配比对
3. 逐项标注国产化合规情况
4. 不通过或存疑的项，给出具体的修改建议

## 数据来源
信创产品库（国产化软硬件产品名录）
