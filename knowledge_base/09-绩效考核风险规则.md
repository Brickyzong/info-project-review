# 绩效考核风险规则

## 审查目的
对续建/改建/运维类项目，评估其历史绩效表现，识别低绩效项目的续建风险。

## 适用项目类型
- 建设类中的**续建**和**改建**项目
- 所有**运维类**项目

## 不适用
- 建设类中的**新建**项目（无历史绩效数据）

## 审查规则

| 条件 | 处理 |
|------|------|
| 上年度有绩效评分，且 ≥ 70分 | **通过**，无风险提示 |
| 上年度有绩效评分，且 < 70分 | **风险提示**："上年度绩效评分低于70分，建议关注项目绩效改进情况" |
| 上年度**未作绩效考核** | **风险提示**："该项目上年度未进行绩效考核，建议完善考核机制" |
| 无上年度绩效数据 | **风险提示**："无法调取上年度绩效数据，建议核实" |

## 审查方法

1. 根据项目名称从绩效数据库中检索上年度绩效评分
2. 与70分阈值进行比对
3. 输出风险提示（如有）

## 输出格式

```
审查项：绩效考核风险
结论：[通过/风险提示]
绩效评分：[分数 / "未考核" / "无数据"]
风险描述：[如有]
建议：[如有]
```

## 数据来源
- 绩效数据库：各项目年度绩效评分
- 当前阶段：使用内置样例数据，后续接入真实绩效数据库
